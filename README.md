A standalone GitHub-compatible git forge written in TypeScript using only the Node standard library — no git binary, no dependencies, no network. It speaks git smart HTTP (upload-pack protocol v2 and v0 plus receive-pack v0, with a hand-built packfile parser/generator and object store), serves the REST v3 API for repositories, issues, pull requests, contents and labels, answers GraphQL v4 queries and mutations with introspection, and exposes the same store over MCP as JSON-RPC 2.0 Streamable HTTP tools, all from a single in-memory store with deterministic timestamps.

## Run it
```sh
node --experimental-strip-types main.ts
```
